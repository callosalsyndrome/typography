**Нефункциональные требования:**

1. Производительность:
   1. Время загрузки страницы каталога типографий: <= 2 сек
   2. Время обработки и валидации файла изображения: <= 5 сек для файла до 50 МБ
   3. Время генерации предпросмотра макета: <= 3 сек
   4. Пропускная способность: >= 100 одновременных пользователей
   5. Время поиска типографий по фильтрам: <= 1 сек
2. Доступность:
   1. Время восстановления после сбоя: <= 1 ч.
   2. Доступность системы: >= 99,5%
3. Безопасность:
   1. Шифрование данных при передаче: TLS 1.3
   2. Шифрование данных при хранении: AES-256
   3. Хранение паролей: bcrypt с солью
   4. Ограничение попыток входа: Блокировка на 15 минут после 5 неудачных попыток.
4. Масштабируемость:
   1. Рост числа пользователей: До 10 000 пользователей без деградации
   2. Рост числа типографий: До 1 000 типографий в системе
   3. Объём хранилища файлов: До 10 ТБ с возможностью расширения
5. Удобство использования:
   1. Интерфейс для роли «Покупатель»: Без технических терминов типографий
   2. Адаптивность: Корректное отображение на экранах от 320px
   3. Поддержка браузеров Chrome, Firefox, Safari, Edge (последние 2 версии)
   4. Время обучения нового пользователя: <= 15 мин до первого заказа
   5. Язык интерфейса: Русский
   6. Количество шагов для оформления заказа: <= 5 шагов
   7. Текст сайта для роли "Покупатель" не должен содержать технические термины типографий.
