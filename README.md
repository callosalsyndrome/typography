-- **Название проекта**: Printing House

-- **Описание назначения**: Система решает проблему того, что по России типографии в основном работают обособленно, пользователю нужно искать типографии в своем городе самостоятельно, изучать разные цены и условия работы для конкретной типографии, также пользователи часто вынуждены сталкиваться с разными способами работы, что представляет типография. Система будет представлять единую систему, объединяющую несколько типографий, с единым алгоритмом формирования заказов под разные параметры. Пользователю будет доступен удобный интерфейс, который доступно покажет категории товаров и цены на печать тех или иных товаров.

-- **Обоснование выбора**

- GitHub и GitHub Issues это главные инструменты разработчика, их легко интегрировать в процесс разработки, т.к. у большей части сред разработки поддержка гитхаба уже встрена в ПО. Из альтернатив рассматривался ГитЛаб, но этот инструмент больше подходит для комплексной разработки внутри закрытых команд (ГитЛаб можно запустить на собственном сервере, но нашей команде это не необходимо).

- Visual Studio и Visual Studio Code содержат множество встроенных инструментов для разработки ПО. Легко связать с ГитХабом. У команды есть много опыта разработки конкретно в этих IDE.

- Опыт работы с СУБД PostgreSQL был у всей команды. Эта СУБД надежна и открыта, бесплатна, поддерживает много форматов данных. Высокая мощность и широкая функциональность.

- Draw.io является бесплатным и легко доступным инструментом для создания прототипов и диаграмм, поддерживает создание самых разнообразных нотаций моделирования, от UML до BPMN и других. Modelio является чуть более удобным и корпоративным инструментом для создания диаграмм UML.

- Postman прост для старта и не требует написания кода для тестирования. Работает с REST, есть гибкая настройка запросов, тестирование можно автоматизировать. Позволяет эмулировать поведение API, когда бэкенд еще не готов, что ускоряет разработку.

- Docker имеет множество преимуществ и является универсальным и безопасным решением для контейнеризации. Контейнеры Docker запустятся на любой машине. Развертывание с Docker - простое и эффективное, т.к. занимает меньше ресурсов. Docker выбран для финального развёртывания; на этапе разработки используется локальное окружение
