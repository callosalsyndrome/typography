-- Название проекта: Printing House

-- Описание назначения: Система решает проблему того, что по России типографии в основном работают обособленно, пользователю нужно искать типографии в своем городе самостоятельно, изучать разные цены и условия работы для конкретной типографии, также пользователи часто вынуждены сталкиваться с разными способами работы, что представляет типография. Система будет представлять единую систему, объединяющую несколько типографий, с единым алгоритмом формирования заказов под разные параметры. Пользователю будет доступен удобный интерфейс, который доступно покажет категории товаров и цены на печать тех или иных товаров.
